# アミの手相｜総合公式HP

以前の総合HPの保存テキストをもとにした、GitHub Pages向けの再構築版です（元サイトの完全コピーではありません）。

## ファイル
- `index.html` ページ構成・文章
- `style.css` デザイン・スマートフォン対応
- `script.js` スマートフォンのメニュー
- `images/` 後から追加する画像の保存場所

## 公開前に確認すること
- 鑑定／講座の公式LINE URL（現在は未設定）
- STORESへの申し込みリンク／レビューリンク（現在は未設定）
- YouTube埋め込み（公開後に追加）
- アミの本人キャラクター画像（現在は仮イラスト）
- 鑑定料金・講座内容・レビューの正確性（保存時点の内容から再構築）
- 感想本文は抜粋・要約で掲載。原文掲載に切り替える場合は改めて確認

## GitHub Pagesで公開
1. GitHubの `Ami-Palm-reading/ami-official` リポジトリに `index.html`, `style.css`, `script.js` をアップロード
2. Settings → Pages → Build and deployment → Deploy from a branch
3. Branch `main`, folder `/(root)` を選んで Save
4. 公開先は `https://ami-palm-reading.github.io/ami-official/` の予定

画像を追加する場合は `images/` に入れて、HTMLの参照を更新してください。
